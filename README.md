# to do list

쉽고 가벼운 할 일 앱(PWA)입니다. 설치·빌드 없이 정적 파일만으로 동작합니다.

**주소:** https://ohseasonhan-coder.github.io/todo-list/ (main 브랜치에 push하면 1분 안에 자동 반영)

## 쓰는 법
- 아래 입력창에 그냥 적고 Enter → 날짜·시간·반복은 문장에서 자동 인식
  - `내일 오후 3시 치과` · `금요일까지 보고서 !` (`!` = 중요)
  - `매주 월요일 9시 운동` · `매달 25일 카드값` · `평일 8:30 출근 체크`
  - `12/24 선물` · `다음주 화요일 아침 7시 30분 병원` · `이번 주말 대청소`
- 동그라미를 누르면 완료(반복 일은 다음 날짜로 넘어감), 실수하면 "되돌리기"
- 할 일을 누르면 편집: 메모, 날짜, 시간, 알림(정시~하루 전), 반복, 중요
- 탭: 오늘(기한 지난 일 포함) · 예정 · 모두 · 완료

## 알림
- 시간이 있는 할 일은 기본으로 정시에 알림이 갑니다. 알림의 **완료 / 10분 뒤** 버튼을 바로 누를 수 있어요.
- 휴대폰에서는 **홈 화면에 설치**한 뒤 알림을 켜야 합니다(아이폰은 iOS 16.4 이상, Safari → 공유 → 홈 화면에 추가).
- 브라우저 앱이 알림 시각을 직접 계산하므로, 휴대폰이 앱을 완전히 종료한 상태에서는 알림이 늦거나 오지 않을 수 있습니다.
  꼭 받아야 하는 일은 편집 화면의 **📅 캘린더에 추가**로 휴대폰 캘린더에 알림까지 함께 넣으세요.

## 빠르게 처리하기
- 할 일을 → 밀면 완료, ← 밀면 내일로 (루틴은 이번 회차 건너뛰기)
- 길게 누르면 빠른 미루기: 1시간 뒤 · 오늘 저녁 · 내일 아침 · 다음 주 (루틴은 시간 대신 다시 알림)
- "기한 지남" 칸의 **모두 오늘로 / 모두 내일로**

## 아침 브리핑
- 설정 → 알림 → ☀️ 아침 브리핑. 매일 정한 시각(기본 오전 8시)에 그날 할 일을 알림 하나로 (할 일이 있는 날만)

## 자동 백업 · 기기 동기화
- 설정 → 자동 백업 켜기 → 동기화 코드 16자리가 생김. 다른 기기에서 이 코드로 연결하면 같은 목록
- 할 일은 기기에서 AES-GCM으로 암호화해서 올라감 (서버는 내용을 못 읽음). 코드를 잃어버리면 복구 불가
- 기기끼리 바뀐 내용은 할 일 단위로 합침(나중에 고친 쪽 우선, 지운 기록도 전달)

## 아이폰 캘린더 · 위젯
- 설정 → 📅 캘린더 구독 켜기 → "아이폰 캘린더에 추가" → 캘린더 앱·캘린더 위젯에 할 일이 일정으로 표시
- 앞으로 60일(루틴 회차 포함), 밀린 일은 오늘 칸에 ⚠, 최근 7일 완료는 ✓
- 이 피드만은 캘린더가 읽어야 해서 평문으로 서버에 저장됨 (주소를 아는 사람만 볼 수 있음). 끄면 서버에서 삭제

## Siri로 추가
- 자동 백업을 켠 뒤 설정 → "Siri로 할 일 추가하기"의 안내대로 단축어를 만들면 "시리야, 할 일 추가"로 등록
- Siri로 넣은 할 일은 다음에 앱을 열 때 목록에 들어오고, 그때 알림이 잡힘

## 루틴 일시정지
- 반복 할 일 편집 화면 → "다시 시작할 날짜" → 일시정지. 그날까지 목록·알림에서 빠졌다가 그날부터 다시 나타남
- 설정 → 루틴 일시정지 → 모든 반복 할 일을 한 번에 멈춤 (여행 등)

## AI 비서 (Gemini)
- 입력창의 ✨ 버튼: 할 일 만들기 / 오늘 계획 / 잘게 쪼개기. 제안 중 고른 것만 추가
- 처음 한 번 설정 → "AI 접근 코드"에 서버에 넣은 코드를 입력

## 서버 (push-server/)
Cloudflare Worker `todo-push` (https://todo-push.ohseasonhan.workers.dev) + D1 DB.
매분 cron으로 알림 시각이 된 할 일을 Web Push로 보냄 → 아이폰 잠금화면에도 표시됨.
- 배포: `cd push-server && npx wrangler deploy`
- 비밀값: `npx wrangler secret put VAPID_PRIVATE_JWK | GEMINI_API_KEY | AI_PASSCODE`
- 테스트: `npm test` (암호화·VAPID 서명 검증)

## 실행 / 배포
- PC에서 바로 보기: `python -m http.server 4400` 실행 후 http://localhost:4400
- 휴대폰에서 쓰려면 HTTPS 주소가 필요합니다. 이 폴더를 그대로 GitHub Pages, Netlify, Cloudflare Pages 등에 올리면 됩니다.
- 데이터는 각 기기의 브라우저에만 저장됩니다. 설정 → 백업 내보내기/불러오기로 옮길 수 있습니다.
