설정

알림

휴대폰에서는 앱을 홈 화면에 설치한 뒤 알림을 켜야 해요. 서버 알림이 연결되면 앱을 닫거나 화면을 잠가도 알림이 와요.

루틴 일시정지

여행처럼 루틴을 못 지키는 기간에는 모든 반복 할 일을 한 번에 멈출 수 있어요.

AI 비서

입력창의 ✨ 버튼으로 말하듯 할 일을 만들거나, 오늘 계획을 짜거나, 큰 일을 쪼갤 수 있어요.

앱 설치

☁️ 자동 백업 · 기기 동기화

켜 두면 할 일이 자동으로 백업돼요. 폰을 바꾸거나 앱을 지워도 되살릴 수 있고, PC에서도 같은 목록을 볼 수 있어요. 내용은 이 기기에서 암호화돼서 서버도 읽을 수 없어요.

다른 기기에서 이미 켰어요 (코드로 연결)

동기화 코드 — 다른 기기에서 이 코드를 입력하면 같은 목록을 써요. 꼭 메모해 두세요. 코드를 잃어버리면 백업을 되살릴 수 없어요.

🎙 Siri로 할 일 추가하기 (단축어 설정)

“시리야, 할 일 추가” → 말하기 → 바로 등록돼요. 아이폰 단축어 앱에서 한 번만 만들면 돼요.

  1. 단축어 앱 → 오른쪽 위 + → 이름을 할 일 추가로 바꾸기
  2. 동작 추가 → 입력 요청 (질문: “무엇을 추가할까요?”)
  3. 동작 추가 → URL 인코딩 (입력: ‘제공된 입력’)
  4. 동작 추가 → 텍스트 → 아래 주소를 붙여넣고, 맨 끝에 변수 ‘URL 인코딩된 텍스트’를 넣기
  5. 동작 추가 → URL의 콘텐츠 가져오기
  6. (선택) 동작 추가 → 결과 보기 → “✅ 추가했어요”가 보이면 성공

Siri로 넣은 할 일은 다음에 앱을 열 때 목록에 들어오고, 그때부터 알림이 잡혀요. 이 주소는 다른 사람에게 알려 주지 마세요.

📱 잠금화면 · 위젯에 할 일 띄우기

할 일이 아이폰 잠금화면과 홈 화면의 캘린더 위젯에 보여요. 3단계면 끝나요.

데이터

할 일은 이 기기의 브라우저에만 저장됩니다.

📱 잠금화면에 할 일 띄우기

  1. 1
    캘린더 구독 켜기

    이 앱의 할 일을 캘린더 형식으로 내보내요.

    ✅ 켜졌어요

    캘린더가 읽을 수 있도록 할 일 제목·메모가 암호화 없이 서버에 올라가요. 구독 주소를 아는 사람만 볼 수 있어요.

  2. 2
    아이폰 캘린더에 추가

    아래 버튼 → 아이폰이 물어보면 구독 → 완료

    캘린더에 추가
    버튼을 눌러도 아무 일도 없으면
    1. 주소 복사를 눌러요
    2. 아이폰 설정 → 앱 → 캘린더 → 캘린더 계정 → 계정 추가 → 기타 → 구독 캘린더 추가
    3. 붙여넣기 → 다음 → 저장
  3. 3
    잠금화면에 위젯 놓기
    1. 화면을 잠그고, 잠금화면을 꾹 누르기
    2. 아래의 사용자화 → 왼쪽 잠금화면 누르기
    3. 시계 아래 위젯 칸(＋) 누르기 → 캘린더
    4. 다음 일정(넓은 칸) 고르기 → 오른쪽 위 완료

    홈 화면에도: 빈 곳 꾹 → 왼쪽 위 편집 → 위젯 추가 → 캘린더 → 목록

💡 더 잘 보이게
  • 시간을 정한 할 일이 위젯에 잘 보여요. (예: “오후 3시 치과”)
  • 빨리 반영되게: 아이폰 설정 → 앱 → 캘린더 → 캘린더 계정 → 데이터 가져오기 → 15분마다
  • 캘린더 앱의 캘린더 목록에서 to do list가 체크돼 있어야 해요.
